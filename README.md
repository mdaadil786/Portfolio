# 🌐 Personal Portfolio — Md Aadil

This is my personal portfolio website built using **HTML**, **CSS**, and **JavaScript**.  
It showcases my skills, projects, experience, achievements, and contact information in a clean and modern UI.



## 🚀 Features

### ✅ Modern UI & Animations
- Clean and professional design  
- Smooth scroll animations  
- Orbit animation around profile picture  
- Responsive design for all devices  

### ✅ Sections Included
- **Hero Section** – Introduction, social links, resume  
- **Skills Section** – Structured and visually appealing skill bars  
- **Education & Highlights** – Timeline format  
- **Projects Section** – Detailed with descriptions & GitHub links  
- **Services Section** – What I offer  
- **Contact Section** – Modern contact form + social icons  
- **Footer** – Auto year update


### ✅ Backend (Spring Boot)
- Hosted using Spring Boot static resources  
- Serves HTML, CSS, JS, and images from `/static`  
- Fast and lightweight
